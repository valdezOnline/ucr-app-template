🔓/🔒 LOCK BUTTON
   • Located in dashboard header (next to display mode selector)
   • Toggles between locked (red) and unlocked (gray) states
   • Real-time updates with zero page refresh
   • Tooltips provide context-sensitive help

📌 PREVENTS ACCIDENTAL DRAGS
   • When LOCKED: Applications cannot be dragged
   • When UNLOCKED: Normal drag-and-drop works
   • Enforced both on frontend (JavaScript) and backend (API)
   • User preference persists across sessions

💾 PERSISTENT STORAGE
   • Lock state saved to database
   • Remembered across browser sessions
   • Works across different devices (per user)
   • Individual preference per user

🔐 SECURE IMPLEMENTATION
   • Authentication required (users must be logged in)
   • CSRF protected (prevents unauthorized requests)
   • User-scoped access (can't modify other users)
   • Zero privilege escalation
