🎯 HOW IT WORKS
══════════════════════════════════════════════════════════════════════════════

For Users:
  1. Navigate to Dashboard
  2. Click the Lock/Unlock button (between display modes and groups)
  3. Button toggles immediately with visual feedback
  4. Preference is saved automatically
  5. When locked: Can't drag applications
  6. When unlocked: Can drag applications to reorder

For Developers:
  → Check lock state: auth()->user()->dashboard_locked
  → Set lock state: auth()->user()->update(['dashboard_locked' => true])
  → API: POST /dashboard/lock (requires CSRF token)
